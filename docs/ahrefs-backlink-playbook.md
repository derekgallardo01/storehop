## 2. Step-by-Step Ahrefs Workflows & Exact Search Strings

### Workflow A: Competitor Backlink Interception (`Site Explorer`)
Find blogs that **already link** to competing grocery list apps. If they link to 5–10 grocery apps in a roundup, they are pre-qualified to add StoreHop.

1. Open **Ahrefs → Site Explorer**.
2. Run these competitor domains one by one (select `*.domain/*` mode):
   - `anylist.com`
   - `ourgroceries.com`
   - `getbring.com`
   - `outofmilk.com`
   - `listonic.com`
3. In the left sidebar, click **Backlinks** (under *Backlink profile*).
4. Apply these exact **Filters** at the top:
   - **Link type**: `Dofollow`
   - **Domain Rating (DR)**: `From 20` `To 75` *(sweet spot: real organic authority, but run by approachable editors/bloggers rather than pay-to-play media conglomerates)*
   - **Domain traffic**: `From 500`
   - **Language**: `English` *(run a second pass with `Portuguese`)*
   - **Group similar links**: `One link per domain`
   - **Referring page title → Contains**:
     - Pass 1: `best`
     - Pass 2: `apps`
     - Pass 3: `grocery`
     - Pass 4: `shopping`
     - Pass 5: `aldi` OR `costco`
5. **Exclude noise**: Ignore APK scraper sites (`apkpure`, `uptodown`, `softonic`, `appbrain`) and focus on editorial blog posts, frugal living sites, meal-planning blogs, and tech roundups.
6. Click **Export** → Add the top 50–100 URLs to your outreach sheet and use **Template 1** or **Template 2** below.
